# MineSweeper

Консольный сапёр под Windows на C++. Школьный проект, июль 2022 года.

Поле рисуется в консоли, цвета цифр и мин задаются через WinAPI, управление — стрелками
с клавиатуры. Есть три уровня сложности: 9×9 с 10 минами, 16×16 с 40 минами и 30×30 с 99 минами.

## Управление

| Клавиша          | Действие                   |
| ---------------- | -------------------------- |
| `1`, `2`, `3`    | выбор уровня сложности     |
| стрелки          | перемещение по полю        |
| `Enter`          | открыть клетку             |
| `Backspace`      | поставить / снять флажок   |
| `Esc`            | выход                      |

Обозначения на поле:

| Символ  | Значение                                        |
| ------- | ----------------------------------------------- |
| `#`     | граница поля                                    |
| `.`     | закрытая клетка                                 |
| `*`     | мина                                            |
| `!`     | флажок                                          |
| `1`–`8` | количество мин среди восьми соседних клеток     |

## Сборка

Проект использует `<windows.h>` и `<conio.h>`, поэтому собирается только под Windows
(проверялось на MinGW-w64 и CLion 2021).

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Готовый `minesweeper.exe` и текстовые файлы `mine.txt` и `choose.txt` окажутся в `build/`.
Файлы должны лежать рядом с исполняемым, иначе заставка и меню выбора уровня будут пустыми.

## Как устроено

- `Field` — поле: расстановка мин, подсчёт цифр, открытие клеток, флажки, проверка победы.
  Заливка пустой области (`Fill`) сделана итеративно, через явный стек, без рекурсии.
- `Cursor` — позиция курсора с возможностью откатить последний шаг, если он привёл на границу.
- `Keyboard` — чтение кодов клавиш.
- `Game` — заставка, выбор уровня, главный цикл игры.
- `GUI` — работа с консолью: размер шрифта, цвета, вывод текстовых файлов, очистка строки.
