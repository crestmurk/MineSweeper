# MineSweeper
Русскоязычная инструкция:
1. Запустите файл MineSweeper.exe
2. Следуйте инструкциям на экране. Нажмите любую клавишу для начала игры.
3. Выберите режим, нажав клавишу '1', '2' или '3'.
4. Для перемещения по полю используйте клавиши со стрелками на клавиатуре.
5. Для открытия ячейки нажмите 'Enter'. Для установки флажка нажмите 'Backspace'.
6. В случае выигрыша или проигрыша Вы увидите сообщение об этом на экране и сможете выйти или начать новую игру.
Обозначения:
'#' - граница поля, на которую и за пределы которой выход запрещён.
'.' - ещё не открытая пользователем ячейка.
'*' - мина.
'!' - поставленный пользователем флажок.
цифры от 1 до 8 указывают на количество мин, расположенных в 8 соседних квадратиках (слева, справа, сверху, снизу и по диагоналям).
